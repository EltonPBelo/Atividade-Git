# Atividade-Git

## Neymidia

Site HTML simples com carrossel de fotos do Neymar nos clubes:

- Santos
- Barcelona
- Paris Saint-Germain
- Al Hilal

Para abrir, execute `index.html` em um navegador.

## Estrutura do projeto

### Pastas

- `/` (raiz do projeto): contém os arquivos principais do site estático Neymidia.
- `css/`: guarda os estilos do site; aqui ficam as regras visuais, incluindo as cores usadas na página.

### Arquivos

- `index.html`: página principal do site, com estrutura HTML e lógica do carrossel.
- `css/style.css`: folha de estilos do site, com a parte visual centralizada e as cores organizadas em um só lugar.
- `README.md`: documentação do projeto e instruções rápidas de uso.
- `LICENSE`: licença de uso do repositório.
